POST /ontology/sparql/
Authenticated CSRF Required

Execute raw SPARQL graph queries against the RDF/OWL knowledge base reasoning engine.

Request Body (JSON or Form)
{
  "query": "SELECT ?crime ?type WHERE { ?crime rdf:type ?type } LIMIT 10"
}
Example Response Payload (200 OK)
{
  "head": { "vars": [ "crime", "type" ] },
  "results": {
    "bindings": [
      {
        "crime": { "type": "uri", "value": "http://crime.ontology.org/incident#101" },
        "type": { "type": "uri", "value": "http://crime.ontology.org/schema#Burglary" }
      }
    ]
  }
}
